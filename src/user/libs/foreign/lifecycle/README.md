# lifecycle

THE FIXTURE FOR AN ADMITTED MECHANISM. The converged closure of the pinned foreign configuration
names exactly one constructor and one destructor, which under this milestone's own rule makes static
initialisation ADMITTED - and an admitted mechanism gets positive gates: its order across the
provider DAG, what a constructor that fails part way leaves behind, its destructors on a normal exit,
and which of them did NOT run when the same process crashes instead.

WHY IT RECORDS INSTEAD OF PRINTING. A constructor runs before the program has adopted a console, so
it cannot say anything; it can WRITE, and the program prints what it finds once it can. The provider
holds the record and the consumer reads it, which is what makes the DAG order visible at all: a
constructor here must run before one in anything built against this.

IT IS A FOREIGN LIBRARY BECAUSE THE MECHANISM IS. `__attribute__((constructor))` is how a C object
gets into `.init_array`, and the closure this milestone measured got there the same way.
