# P01M0009 - StorageService over virtio-blk

Status: COMPLETE.

The same service component as the phase-0 ramdisk version - only its backend changed.

*Condensed 2026-08-08.*

**A path is a typed object, and a URI is only a representation.** `VolumePath { volume, path }` where
the path is a list of validated segments rather than a string, so `..` and `/` traversal **has
nowhere to arise** - it is not defended against, it is unrepresentable. Authority is the capability,
never the spelling.

A path belongs to exactly one volume; if the volume is gone, the operation fails rather than
resolving somewhere else.

Getting there needed the IDL toolchain to learn **capability transfer**: the codec carries one
out-of-band handle per message - the kernel channel's single-handle slot - and the transport threads
it both ways. The generator emits it for handle-typed fields as a placeholder in-stream plus the
capability out of band, **so a future multi-handle index form stays wire-compatible**.

Deliberately deferred and recorded: the broader namespace resolvers, per-process namespace
composition, and cross-volume transfer. The direction was fixed, not the API.
