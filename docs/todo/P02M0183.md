# P02M0183 - A typed modem service

Status: OPEN. It closes when every item below is done, and not before.

**NETWORKSERVICE IS NOT THIS.** P02M0099's USB CDC-MBIM item states the gap in one line:
NetworkService alone does not carry SIM, network or link state. A mobile-broadband device is not a
network card with a cable - it has a subscriber identity, a registration state, an operator, a
signal quality, a set of contexts that may be activated, and each of those is a fact a client may
need and NONE of them is an IP-layer concept. Passing IP datagrams to NetworkService is the easy
half; the half with no owner is everything that decides whether there are datagrams to pass.

**AND IT EXISTS BECAUSE THE OWNER SAID SO (2026-09-21)**, answering P02M0099's question about the
nine unowned destinations.

## The shape

- [ ] A typed `liber:modem@1` interface: devices, SIM state, registration, operator, signal, and
  the contexts a client may ask to activate. Typed, because "the modem's state as a string" is what
  every system that has this ends up regretting.
- [ ] THE SUBSCRIBER IDENTITY IS NOT AMBIENT. IMSI, ICCID and the phone number are identifiers that
  follow a person; reading them is a separate capability from using the link, and the ordinary
  client of a data connection gets the second and not the first.
- [ ] PIN and PUK entry with attempt counters surfaced honestly - a client that cannot see how many
  attempts remain is a client that will burn the last one.
- [ ] Context activation that hands NetworkService a link under an EXPLICIT grant, which is the
  word P02M0099's item uses: the modem service does not reach into the network stack and the
  network stack does not reach into the modem.
- [ ] Bounded outstanding transactions and datagrams, so a device that stops answering cannot grow
  a queue without end.
- [ ] Host tests over the control-message fragmentation, the session and NDP tables, and every
  malformed shape MBIM's framing admits.
- [ ] A guest gate over the observable effect, registered in the verification model in the same
  change.

## Definition of done

Done when a client holding the data capability can activate a context and pass traffic through
NetworkService under an explicit grant; when SIM identity is a separate capability nothing hands out
by default; when the fragmentation and table decisions are host-tested against hostile input; and
when the guest gate and its model entry land with the code.

## What it unblocks

P02M0099's **USB CDC-MBIM**.
