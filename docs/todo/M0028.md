# M0028 - Minimal WASI host: the first Wasm component

Status: COMPLETE.

A Wasm component runs end to end and reads a file it was granted, through a host import mapped onto
StorageService.

*Condensed 2026-08-08.*

**A WASI world is the set of capabilities a component receives at startup** - there is no ambient
authority, so a component's world *is* its sandbox rather than something enforced around it. The host
process is given only a StorageService client, and that is the whole of what it can pass on.

The runtime is a `no_std` crate, host-tested: a binary-format parser producing a module, and a small
stack-machine interpreter over the integer subset whose imported calls dispatch through a `Host`
trait. **That trait is the seam where a component reaches native services**, and keeping it a trait
is what let the interpreter stay testable on the host.

Deliberately minimal: no control flow or floats yet, and the full Component Model, WASI preview 2 and
an SDK were left to the later milestone.
