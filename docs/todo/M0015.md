# M0015 - Framebuffer text console

Status: COMPLETE. *Condensed 2026-08-08.*

A linear RGB mode from the boot loader, handed to a portable console module that renders an embedded
8x8 bitmap font at 2x scale, packing each pixel per the mode's own colour mask shifts - so it does not
assume a channel order.

**The log is mirrored, not redirected.** The print macros write to serial **always**, then to the
console **best-effort under a try-lock** - so a panic mid-print can never deadlock the logger, and
serial always wins. The console is a no-op when the boot loader provided no framebuffer.

Validated by screendumping the headless framebuffer over the monitor socket and reading the whole
boot log off it, having scrolled correctly. The on-screen mirror needs no unit test: it is pure
output, and a screenshot is the assertion.
