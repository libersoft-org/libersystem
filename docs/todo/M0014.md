# M0014 - Init package and the first userspace process

Status: COMPLETE. The kernel loads an init package and runs SystemManager in ring 3, which sends the
first IPC message.

*Condensed 2026-08-08.*

The userspace program is a freestanding `no_std` ELF linked **non-PIE as `ET_EXEC` with no
relocations**, because the kernel's loader applies none - the executable's link-time addresses are
where it is mapped. Its entry aligns the stack and calls into main with the bootstrap channel handle
arriving in a register, which is how a process is endowed with its first capability.

`PKGARCH1` is the archive format: a small header of magic and count, fixed-size entries of a
NUL-padded name plus offset and size, then the blobs. The kernel's parser validates every range.

One build-system decision worth keeping: **if the userspace ELF is absent the build writes an empty
package and warns**, so a bare `cargo build` and rust-analyzer still succeed. A build that fails
because an unrelated artifact is missing makes the editor useless.

*(M0138 later retired the archive from the boot path entirely - the loader reads the programs from
the filesystem instead.)*
