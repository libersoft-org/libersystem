# P02M0074 - Architecture sweep: memory protection, the display path, and the plumbing debt

Status: COMPLETE. A full-tree review (kernel, services, drivers, tools, shared crates) that collected
everything with no milestone of its own. Findings that already had one were deliberately left where
they were rather than duplicated here.

*Condensed 2026-08-08 to the mechanisms this sweep introduced that are still load-bearing, and the
defects worth not reintroducing.*

## W^X on x86_64

`paging::NO_EXECUTE` (bit 63) with `enable_nx()` - CPUID-gated EFER.NXE, run on the BSP with the
descriptor tables and first thing in every AP's bring-up. Where NX is unsupported the bit is
stripped at `map_page_in`, so an old CPU still maps rather than failing.

Every data mapping now carries NX: the kernel heap window, MemoryObject / DmaBuffer / framebuffer
maps in both rings, DeviceMemory MMIO, the LAPIC / IOAPIC / MSI-X windows, the ELF loader's ring-3
stack, and every non-`PF_X` segment. The userspace linker script already separates text from rodata
and data, so code stays non-writable.

## `WAIT_PERIODIC` - a first-class recurring wake

The cooperative boot driver treated any perpetually re-armed deadline as "not idle", so a periodic
housekeeping waiter kept `run_until_idle` from ever settling. `WAIT_PERIODIC` is a flag on `wait`
and `wait_any` marking a deadline as recurring: the waiter is still woken when due, but
`min_deadline` skips periodic waiters so `run_until_idle` settles across them.

This is still the mechanism every housekeeping loop uses, and it fixed a visible symptom - the
boot-chain reports (`userspace: X: online`) had never printed, because supervise sat inside
`run_until_idle` forever.

## The display path

- **virtio-gpu uses the configuration-change interrupt** instead of a ~200 ms `GET_DISPLAY_INFO`
  poll. DeviceManager acquires the per-device MSI-X vector and hands it over as the standard IRQ
  message; only the CONFIG vector is routed there, so the control queue stays polled. The
  acknowledgement order matters and is deliberate: `events_read` → `events_clear` → `interrupt_ack`
  **before** re-reading the size, so a change racing the handler fires again instead of being lost.
  With no interrupt granted the loop falls back to the old poll, now as a `WAIT_PERIODIC` wake.
- **Dirty-rectangle present.** The renderer accumulates a pixel bounding box of everything it paints
  - cells, whole scroll bands, the caret and its erasure, with blink, clear, scrollback and the bell
  as full-frame marks - and `Term::present` sends **nothing** when nothing was painted. The driver
  coalesces a backlog by uniting queued rectangles, clamps to the visible scanout and transfers with
  the sub-rectangle's byte offset.

## The serial mirror was silently truncating

The stall had already been retired by the bulk write and async transmit ring, but **a burst larger
than the ring's free space had its tail dropped**, with nothing reporting it. The whole chain now
reports acceptance: `serial::write_bytes` returns how many source bytes the ring took (stopping
cleanly at a `\r\n` pair), the bulk `SYS_DEBUG_WRITE` returns that count, `rt` gained `debug_write`
returning the accepted count while `print` stays fire-and-forget, and the console carries the
remainder to a later wake.

## The rest, in one line each

- **A typed bootstrap handshake** replaced the ad-hoc positional tagged-capability protocol
  (`b"STORAGE"`, `b"NET"`, …), where every new service meant touching ServiceManager, ConsoleService,
  the shell and the tests in step.
- **xhci parses HID report descriptors** instead of assuming the boot protocol, so non-boot keyboards
  and USB pointers work.
- **DHCP honours T1/T2** rather than holding the first lease forever.
- **A real wait-for-exit**, instead of relying on the child's final "done" send.
- **The mmap VA bump allocators reuse released ranges** - both the kernel window and the per-process
  user window previously never did.
- `kernel/main.rs` (~4.4k lines) split its boot scenarios and test suite into modules.
- Manifests distinguish **requested** from **granted**, where before only the granted set was
  recorded.
