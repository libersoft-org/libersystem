# M0098 - ISO9660: third-pass findings (the root XAR and associated files)

Status: COMPLETE. The third full source pass (2026-07-04); only low and cosmetic leftovers.

*Condensed 2026-08-08.*

**The previous pass's XAR fix was incomplete**, which is the useful part: the record parser advanced
past the attribute blocks, but **the root record lives in the volume descriptor and goes through a
different path** that did not. A root directory behind an XAR block still parsed the attribute block
as records. A fix applied at one of two entry points is half a fix.

**Associated files were not hidden.** A secondary stream is recorded *before* its same-named main
file, so the name listed twice and a lookup took the fork - wrong content served. Skipped in parsing,
so they neither list nor match.

Recorded as a known limit rather than implemented: Rock Ridge deep-directory relocation is not
interpreted, so a tree mastered deeper than eight levels shows the mastering tool's artifacts where
it placed them. Everything stays reachable, which is why it is a limit and not a defect.
