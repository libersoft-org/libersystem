# M0017 - Simple CLI + basic System Graph

Status: COMPLETE.

A minimal serial CLI and the first introspection: enumerate live Domains, their processes, and every
handle each one holds.

*Condensed 2026-08-08.*

`SYS_OBJECT_INFO_GET` returns a repr(C) record for a handle, whose `object_type` is **a stable ABI
code decoupled from the in-memory enum order** - so reordering the enum cannot silently change what
userspace sees. An unknown handle returns the bad-handle error rather than a zeroed record.

The System Graph walks the live tree from the root Domain: per Domain its quota usage and its
processes, each process's handles snapshotted as capability records, then recursion into children.

**One thing had to be worked around and is worth remembering.** For the kernel to drive the userspace
storage service as its own client, a persistent server busy-yielding would never let the cooperative
scheduler's idle loop drain - so the kernel's read sends its request followed by a quit sentinel.
That is the shape of problem the blocking `wait` primitive (M0018) was built to remove.
