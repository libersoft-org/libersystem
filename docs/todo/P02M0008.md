# P02M0008 - Observability (full System Graph, tracing, counters, CBOR)

Status: COMPLETE (2026-06-27).

The appliance runs unattended, so it needs real observability rather than a boot-time picture.

*Condensed 2026-08-08.*

- **The IDL toolchain gained CBOR**, its fourth representation: `lsidl-gen` emits a `to_cbor` pair for
  every record, so a binary rendering exists for every type without anyone hand-writing one.
- **SystemGraphService exposes the full live graph** over generated bindings - services, drivers,
  devices and the dependencies between them, labelled.
- **Per-component counters and tracing**: IPC volume, restarts, resource usage.
- The shell renders all of it as CLI, JSON or CBOR from the same source, so the three cannot drift.

The point of generating the renderers rather than writing them is that an observability format nobody
maintains stops matching the thing it observes.
