# P00M0002 - Memory foundation

Status: COMPLETE. *Condensed 2026-08-08.*

The physical frame allocator threads its free list **through the free frames themselves** via the
higher-half direct map, seeded from the boot memory map's usable regions - so the allocator needs no
metadata allocation of its own to start.

Paging walks and creates the four-level tables on the active CR3. The kernel heap is a linked-list
first-fit global allocator over a 1 MB mapped window, which is what turns on `alloc`.

The first spinlock - a test-and-test-and-set lock guarding the shared frame allocator - was written
correctly from the start rather than as a placeholder, because everything above it inherits its
correctness.

*(The free list was later replaced by a range table in P02M0042, for contiguous allocation.)*
