# P02M0065 - FAT: ninth-pass findings (FAT mirroring flags and overwrite fidelity)

Status: COMPLETE. The ninth full source pass (2026-07-04), after the spec corners no earlier round
had read.

*Condensed 2026-08-08.*

**The FAT32 `BPB_ExtFlags` word was ignored, and that can cross-link real data.** Bit 7 set means FAT
mirroring is **disabled** and only the copy named by bits 0-3 is current - the others are stale *by
specification*. Every read used copy 0 unconditionally, so on such a volume the crate followed wrong
chains and the allocator handed out clusters the active FAT held allocated. Writes landing on all
copies limited the damage without removing it.

Now: the active copy and the mirror flag are parsed into the geometry, reads use the active copy,
writes touch every copy only when mirroring is on, and an exFAT volume with `ActiveFat = 1` (TexFAT)
refuses to mount rather than being half-supported.

**An overwrite was delete-plus-create**, so a file overwritten here got a fresh creation timestamp
and the newly given name case - where the media's home systems preserve both. Both swap paths now
carry the replaced entry's creation stamp and reuse its name when it matches case-insensitively; the
modify stamp stays fresh.

One documentation correction worth recording: the exFAT specification **excludes** `VolumeFlags` and
`PercentInUse` from the boot checksum precisely so a driver can update them in place. An earlier
claim that maintaining them would cost a checksum restamp was wrong. The dirty flags stay untouched
and the trade-off is recorded rather than silently skipped.
