# M0087 - FAT: hostile-media robustness (no panic, no hang on any boot sector or chain)

Status: COMPLETE.

The crate's whole job is mounting foreign removable media - **the least trustworthy bytes in the
system** - and several malformed-but-plausible boot sectors panicked or hung the storage service.

*Condensed 2026-08-08.*

- **A shift overflow in the exFAT geometry.** `1u32 << b[108]` with a byte past 31 panics in a debug
  build and, worse, **wraps in release** - an exponent of 41 becomes 9, yielding a plausible geometry
  that passes validation. Both exponents are bounded before shifting.
- **Unchecked BPB arithmetic.** A forged sector layout underflowed on subtraction and overflowed on
  `num_fats * fat_size` before that. The region arithmetic runs in u64 and refuses a layout whose
  regions reach or exceed the sector count.
- **`last_cluster` was the one FAT walk with no cycle guard**, so a cyclic chain hung the grow path
  forever. Worse: a chain reaching a free entry walked to cluster 0, whose FAT slot is the media
  descriptor and reads as end-of-chain - so the grow then **overwrote FAT[0]**.
- **The grow path could panic on a long name.** A full directory grew exactly one cluster and wrote
  the entry set without rechecking; a 255-byte name is a 672-byte set, which overruns a 512-byte
  cluster. The slot search re-runs after each grow.
- The boot-sector signature at offset 510 was never checked.
