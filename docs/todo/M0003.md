# M0003 - SMP

Status: COMPLETE. *Condensed 2026-08-08.*

Application processors are woken through the boot loader's MP response, each jumping to its entry on
its own provided stack, and the boot processor spins until every core has reported in.

Two details that are easy to get wrong and are worth keeping:

- **The GDT carries a per-core TSS** - each core loads its own, because a busy TSS cannot be loaded
  twice - while the IDT is shared. Each AP programs its own LAPIC and syscall MSRs.
- **Reporting in happens before the online count is bumped, under a lock**, so the boot processor's
  resumed serial output never interleaves with the AP lines.

Per-CPU state is parked through the GS-base MSR.
