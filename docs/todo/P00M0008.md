# P00M0008 - IPC

Status: COMPLETE. *Condensed 2026-08-08.*

A `Channel` is a connected endpoint pair. **Each end owns its inbox and holds the peer weakly**, so
the two ends never form a reference cycle - which is what lets a closed end be observable rather than
leaked.

Send and receive are non-blocking with typed outcomes, including peer-closed, distinct from empty. A
message carries a payload, transferred capabilities and a sender badge.

**Capability transfer consumes the source handle only on success**, so a failed send drops nothing -
the caller still holds what it tried to give away.

`Event` (a signalable latch) and `Timer` (one-shot against the tick) are the other pollable objects.
A true blocking `wait` was deliberately deferred to P01M0001; until then consumers polled and yielded.
