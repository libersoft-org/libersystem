# P00M0003 - Time and interrupts

Status: COMPLETE. *Condensed 2026-08-08.*

The Local APIC comes up in xAPIC MMIO mode - **its page is mapped explicitly non-cacheable**, since
the boot loader's direct map does not cover it - the legacy PICs are masked, and a periodic timer
runs at 100 Hz, calibrated against a PIT channel rather than trusted.

Interrupt dispatch goes through a **lock-free handler table**: function pointers stored as atomics,
so dispatch is safe in interrupt context without taking a lock that an interrupt could contend.
Registration installs a handler by vector.
