# P02M0174 - IPv6 at layer three: addressing, ICMPv6 and neighbour discovery

Status: FUTURE TRACK. NETWORKING FOUNDATION. NOT A PHASE-2 COMPLETION GATE.

## Goal

Add a bounded IPv6 host layer beside the existing IPv4 stack: canonical addresses, Ethernet IPv6,
strict packet parsing, ICMPv6, neighbour discovery, duplicate-address detection, router discovery and
SLAAC. IPv4 remains operational throughout.

This mirrors P02M0003's layer boundary. It does not yet change every public NetworkService operation
or add IPv6 TCP/DNS tooling; P02M0175 owns that transport/API migration after the L3 behavior is
proven.

## Work

- [ ] **M1 - IPv6 values are typed and scoped.** Introduce canonical 128-bit address, prefix and
  route types with checked construction and classification for unspecified, loopback, multicast,
  link-local and global addresses. A link-local address is never used without the interface/scope
  which gives it meaning. Derive the stable link-local interface identifier by one documented local
  policy; do not accidentally expose an unreviewed hardware identifier as a privacy claim.

- [ ] **M2 - Ethernet/IPv6 parsing is strict and bounded.** Support EtherType `0x86dd`, the fixed
  IPv6 header, payload-length and next-header validation, hop limit, multicast destination filtering
  and egress construction. Walk extension headers under explicit byte/count limits and implement
  their unknown-option action bits; reject deprecated routing forms and malformed chains. A payload-
  length-zero packet carrying a Jumbo Payload option (or trailing payload without a declared length)
  is refused unless a separately bounded jumbogram design is added; a genuinely empty payload stays
  valid. This milestone's MTU and buffer model does not support jumbograms. Preserve P02M0003's
  deliberate no-fragmentation policy: do not generate fragments, refuse Fragment headers rather than
  partially reassemble them, and return a typed too-large result when a payload exceeds path MTU.

- [ ] **M3 - ICMPv6 is part of the host, not an optional ping codec.** Validate the IPv6
  pseudo-header checksum and implement echo request/reply plus the errors needed by this host:
  Destination Unreachable, Packet Too Big, Time Exceeded and Parameter Problem. Errors quote only a
  bounded portion of the triggering packet and are not generated in response to cases forbidden by
  ICMPv6. Maintain a bounded path-MTU cache with a floor of 1280 and expiring entries. A Packet Too
  Big update is accepted only when its quotation matches a recent packet emitted by this host on that
  route and its advertised MTU lowers the current value; unmatched, stale, increasing and replayed
  quotations cannot poison the cache.

- [ ] **M4 - neighbour discovery replaces ARP for IPv6.** Implement solicited-node multicast,
  Neighbor Solicitation/Advertisement, Router Solicitation/Advertisement and the reachable/stale/
  incomplete state needed by the current single-interface appliance. Validate hop limit 255,
  source-address rules, target legality and exact option lengths before learning anything. Cache
  entries, pending packets, retries and per-tick work are bounded; unsolicited/flooding ND cannot
  allocate or log without limit.

- [ ] **M5 - DAD and SLAAC have explicit lifetimes.** Form a tentative link-local address, perform
  duplicate-address detection before use, process valid autonomous RA prefixes into a bounded set
  of tentative global addresses, and run DAD for every newly formed unicast address before it becomes
  usable. Maintain preferred/valid lifetimes, default-router lifetime and advertised MTU. The
  conventional IID-based SLAAC path forms an address only from a Prefix Information option with
  `A=1` and a /64 prefix; `L` is evaluated independently, and only `L=1` installs the prefix as an
  on-link route. Other lengths are not silently truncated into an address.
  Expiry deprecates then removes state, clears/refuses pending L3 packets and publishes one bounded
  address/route invalidation event for P02M0175's transport layer. Accept a bounded set of RDNSS
  servers for the later resolver, validate their option lifetime, withdraw on lifetime zero or
  overflow-safe expiry, and publish the DNS-configuration change. A hostile RA cannot install an
  invalid prefix, an MTU below 1280, an off-link next hop, or immortal state through arithmetic
  overflow.

- [ ] **M6 - packet fixtures and QEMU prove both positive and hostile paths.** Host tests cover
  address classification, checksums, extension walking, ICMP errors, DAD conflict, ND state/lifetime,
  RA validation, RDNSS withdrawal/expiry, jumbogram refusal, matched/unmatched PMTU quotations and
  cache exhaustion. A named QEMU IPv6-L3 gate configures an explicit reviewed global-unicast /64 and
  DNS/router addresses rather than accepting QEMU user networking's deprecated default site-local
  prefix as a global-address oracle. The guest obtains link-local and SLAAC global addresses,
  resolves the router at L2, exchanges echo traffic and observes Packet Too Big, while malformed
  extension/ND/RA and flood fixtures are refused within fixed resource bounds. The same boot retains
  its IPv4 address and ping path.

## Dependencies

- P02M0002 owns the virtio-net frame transport.
- P02M0003 owns Ethernet/IPv4/ARP/ICMP and the existing fragmentation refusal.
- P02M0004 owns the NetworkService seam which will consume this layer in P02M0175.

## Definition of done

- A QEMU appliance configures valid link-local and SLAAC addresses and exchanges ICMPv6 without
  regressing IPv4.
- ND, RA, extension-header and PMTU processing are fail-closed and bounded under hostile input.
- No partial IPv6 fragmentation/reassembly or unscoped link-local address is presented as supported.

## What this milestone refuses

- UDP/TCP/DNS/public NetworkService migration, which is P02M0175.
- DHCPv6, temporary/privacy addresses, router forwarding, firewall/NAT, IPsec, VPN or Wi-Fi policy.
- Full fragment reassembly; it can be proposed later with its own memory and timeout budget.
