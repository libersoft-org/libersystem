# P00M0010 - Resource accounting

Status: COMPLETE. *Condensed 2026-08-08.*

A `Domain` carries an account of memory bytes, handles and threads, each **a single atomic
check-and-add**, so charging is SMP-correct without a lock.

Two decisions that shaped everything later:

- **Charging happens at the boundary of the create paths and is enforced**: an over-cap create returns
  a typed resource-exhausted error rather than crashing.
- **Refunds are Drop-based and exactly balanced.** The handle table refunds on drop, a memory object
  frees its frames and refunds on drop, a thread refunds its slot - so **even a crashed thread leaves
  the account at zero**, with no cleanup path to forget.

Memory is charged at object creation, not at mapping: a mapping consumes address space, not RAM, so
counting both would double-count.
