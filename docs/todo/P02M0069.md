# P02M0069 - UDF: first-pass audit (no hostile-media bounds at all)

Status: COMPLETE. The first full audit pass over the UDF backend (2026-07-04), with the discipline of
the FAT and ISO9660 tracks: the crate reads foreign media, so every number on it is untrusted.

*Condensed 2026-08-08.*

- **The File Entry's allocation-descriptor length was trusted.** The descriptor region clamps to the
  File Entry block now.
- **`read_icb` allocated from a length off the medium.** The Partition Descriptor supplies the real
  partition length; the mount refuses a zero length or a File Set past it and probes the last block,
  so the medium bounds the claim.
- **`read_dir` reported each file's size by reading its entire contents.** A listing now reads one
  bounded, checksummed header block per file. Listing a directory should not cost what reading it
  costs.
- **The allocation-extent type was ignored** - the length's top two bits distinguish recorded,
  unrecorded and continuation extents. All three are handled: a sparse extent reads back as zeros
  rather than as whatever stale bytes it points at.
- **Descriptor tag checksums were never verified**, though the format makes them mandatory. Verified
  at the anchor, every volume descriptor and the File Set.
