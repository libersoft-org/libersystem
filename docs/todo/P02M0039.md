# P02M0039 - Demand-paged user stacks

Status: COMPLETE. **The kernel's first resumable fault.**

User stacks were fully mapped up front, so a deep call chain - the Wasm interpreter over a generated
client over the codec - needed a compile-time stack budget.

*Condensed 2026-08-08.*

The loader eagerly maps only the top eight pages of a new process stack. The page-fault handler
recognises a ring-3 not-present fault **inside the stack span, below the top and at or above a hard
floor** as growth: it maps a zeroed page and returns, so the faulting instruction simply retries.

The distinctions are the whole design. A **protection** fault - the present bit set - is not growth. An
address outside the span is not growth. Exhausted memory still terminates. And **the lowest page of
the span is a never-mapped guard**, so runaway recursion dies instead of growing forever.

With only touched pages costing memory, the reserved span could grow to megabytes - and the ceiling
became a per-Domain resource limit set by policy rather than a global constant. That is the
milestone's second point: **budgets replaced by growth, with the bound moved to where policy lives.**
