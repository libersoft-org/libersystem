# M0013 - Domain hierarchy and lifecycle

Status: COMPLETE.

Domains form a tree - a weak parent link, strong children, and weak back-references to the processes
under each node.

*Condensed 2026-08-08.*

**Charges walk up.** Each resource charge hits the node's own account and then every ancestor, and a
charge that fails at an ancestor **rolls back the levels it already charged** - so a process can
exceed neither its own limit nor any enclosing aggregate, and a partial charge is never left behind.

**Killing a Domain is a subtree teardown**: set the killed flag, terminate each live process at the
node - collected outside the lock - then recurse. A terminated process eagerly closes its handle
table, refunding handles and dropping memory objects so the frames come back immediately, while its
threads exit cooperatively: **`yield_now` is a kill point** that exits when it observes its process
was killed while descheduled.

## The gotcha, which recurred

`yield_now` must drop its `Arc<Thread>` temporary **before** calling the no-return exit - holding a
drop-bearing clone across that longjmp leaks the reference and pins the thread slot. This is the same
class of bug M0012's fault path had, and it is the kind that leaves no trace at the point of failure.
