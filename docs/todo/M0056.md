# M0056 - LiberFS: snapshots

Status: COMPLETE. *Condensed 2026-08-08.*

The copy-on-write work had left the groundwork - the previous root stays reachable and can be mounted
read-only. This finished it into a feature.

Named snapshots pin a generation's root so its blocks are not reclaimed; several are retained, listed
and deleted individually, and the whole thing is managed through the typed volume interface so the
shell can drive it.

**`fsck` and the free-map derivation account for every pinned generation**, which is the part that
makes retention safe rather than merely possible: a free map that forgets a pinned snapshot will
allocate over it.
