# P02M0181 - A platform power-state service

Status: OPEN. It closes when every item below is done, and not before.

**WHAT EXISTS TODAY IS TWO VERBS.** `system-power` carries `reboot` and `power-off` and nothing
else. That is enough for the chassis power button, which P02M0099 completed against exactly those
two, and it is not enough for anything that has to SAY something about power rather than act on it:
a UPS reporting that it is on battery, a laptop battery at eleven per cent, a thermal zone that has
crossed a trip point, a suspend request that has to quiesce devices before it can be honoured.

**SO THE DRIVERS HAVE NO DESTINATION.** P02M0099's USB HID Power Device item says it plainly - the
platform power-state service is named and unowned, so a UPS driver has no typed place to publish to
and no observable effect a gate could assert. The same is true of the ACPI battery, AC and thermal
classes, which are blocked three times over and this is one of the three.

**AND IT EXISTS BECAUSE THE OWNER SAID SO (2026-09-21)**, answering the question P02M0099 put about
all nine destination services at once.

## The shape

- [ ] A typed `liber:power@1` interface with two halves that are not the same thing: STATE, which
  anybody may read, and CONTROL, which is capability-gated. A client that can see the battery level
  must not thereby be able to shut the machine down.
- [ ] A normalized vocabulary for a source of power and a consumer of it: present, charging,
  discharging, charge and design capacity, voltage, current, runtime remaining, and the alarms. It
  is normalized because a UPS over HID and a battery over ACPI report the same facts in different
  units, and a service that passed either through unchanged would make every client parse both.
- [ ] Thermal zones and their trip points, as readings and thresholds rather than as actions. What
  to DO about a trip point is policy and belongs to whatever owns policy.
- [ ] Subscription with bounded queues and coalescing. A battery that reports every milliamp is a
  device, not an event source; clients get changes at a rate the service decides.
- [ ] SUSPEND IS NAMED HERE AND NOT BUILT HERE. P02M0099 separated it deliberately: suspend is a
  platform-lifecycle feature with its own device-quiesce, memory and wake contract, and it is a
  separately approved item. This file is where its prerequisite state lives, not where it lands.
- [ ] Host tests over the normalization and the alarm decisions, with the malformed cases each
  source can produce.
- [ ] A guest gate over the observable effect, registered in the verification model in the same
  change.

## Definition of done

Done when a client holding the read capability can enumerate power sources and thermal zones and
subscribe to changes with a bounded queue; when the control half is a separate capability nothing
hands out by default; when at least two sources - one HID, one ACPI - publish through one normalized
vocabulary; and when the host tests and the guest gate are in the same change as the code.

## What it unblocks

P02M0099's **USB HID Power Device class**, and one of the three blockers on **ACPI battery, AC and
thermal classes**.
