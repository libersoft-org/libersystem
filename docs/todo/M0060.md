# M0060 - UDF filesystem backend (read-only, DVD / Blu-ray)

Status: COMPLETE. *Condensed 2026-08-08. The three later audit passes (M0099-M0101) are where it
became hostile-media safe - including the shared-buffer defect that was the most serious of the whole
filesystem series.*

DVDs and Blu-ray discs are UDF rather than ISO9660, so the ISO backend covered CDs and stopped there.

The backend reads the anchor and the volume and partition descriptors, walks the File Set and the
directory information control blocks, and reads files with long Unicode names. Read-only: no
allocation, no write path.

Same shape as its siblings - behind the one volume interface, host-testable through the shared
block-device trait against an image fixture, with a live read in the guest.
