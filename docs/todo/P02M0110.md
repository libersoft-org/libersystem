# P02M0110 - The build interface: scripts with flags, and a Justfile that stops being one

Status: COMPLETE. `just --list` printed 123 recipes. That was the entire discovery surface for
building, running, testing and imaging the system, and at 123 entries nobody reads it - people learn
four commands and never find out the other 119 exist.

*Condensed 2026-08-08.*

## What replaced it

| was | is |
|---|---|
| 23 `dev-*` recipes | `./dev.sh <verb>` |
| 12 `*-conformance` | `./check.sh --conformance [format]` |
| 16 `*-check` | `./check.sh [--gate name]` |
| 30 `test*` | `./test.sh --arch <a> [--tags ...] [--fast] [--build-only]` |
| every `*-aarch64` / `*-riscv64` pair | `--arch` |
| the build recipes | `./build.sh --part ...`, with prerequisite guards written explicitly |
| the image recipes | `./image.sh --format iso\|img\|qcow2 --size <n>` |

The reasoning for scripts rather than a smaller Justfile: a matrix belongs in flags, not in
generated recipe names. `test-tags-build-fast-aarch64` is three orthogonal choices spelled as one
identifier, and there is no way to discover the fourth.

## Two things that took a second pass

**Refusing a stale build.** `require_built` already refused a missing loader; it had to refuse a
stale system volume or service set too, because a suite that silently tests the previous build turns
every verdict into a guess. The guard needed correcting twice before it was right.

**Running three architectures at once.** This needed the unqualified `init.pkg`, `volume.pkg` and
`kernel` names in `.build/boot` to become per-architecture first - two concurrent runs were writing
the same paths. `aavmf-vars.fd` is shared as well, which only matters between two aarch64 runs but is
the same class of problem. Only after that could `--arch all` run them concurrently; Cargo serialises
the compile through its own lock regardless.

## The part that goes stale

`INSTALL.md` and every other document naming a recipe went stale within hours of the change. Anything
that names a command in prose is a copy of the interface, and copies drift.
