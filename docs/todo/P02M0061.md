# P02M0061 - FAT: fourth-pass findings (read-side name integrity and the last layout gates)

Status: COMPLETE. The fourth full source pass (2026-07-04).

**Name integrity was never verified on read.** The classic parser paired VFAT long-name fragments
with whatever short entry followed, without checking that they belonged together. The long-name run
is a validated unit now: the 0x40 fragment opens it, the rest must count the sequence down carrying
the same checksum, and the run pairs with the short entry only if the checksum agrees.

*Condensed 2026-08-08.*

- Two more degenerate or overlapping layouts refused at mount.
- **Grow linked a fresh cluster into the directory chain before zeroing it on disk**, so entry-like
  garbage could be read as entries in the window. Both grow paths zero first; a failure still frees
  the cluster.
- The classic allocator read the FAT per candidate cluster; it reads one in-memory image of the first
  copy and scans that, with out-of-image offsets reading as non-free.
- An all-spaces classic entry with no long name is skipped, like the exFAT arm already did.
- An I/O error mid-walk in `free_chain` lost the count of what had been freed; the walk and the
  adjustment are separate now, so the count reflects whatever was actually freed.
