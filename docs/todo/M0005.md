# M0005 - Threads, address spaces, scheduler

Status: COMPLETE. *Condensed 2026-08-08.*

A `Thread` owns its 16 kB kernel stack and its saved stack pointer; an `AddressSpace` wraps a CR3,
though at this point every kernel thread shares one. The context switch is hand-written assembly
saving and restoring the callee-saved registers and swapping stacks, with a trampoline that calls the
entry point and then exits.

**The run queues are per-CPU from the start** - SMP-correct before SMP scheduling existed, with no
migration yet. Cooperative round-robin: spawn, spawn-on-a-core, yield, exit, run-until-idle.

**The switch is leak-safe by construction**: the outgoing thread is moved into a zombie or requeue
slot *before* the stack swap, so a retiring thread's stack is freed cleanly from the context that was
switched to - never from the stack being freed.
