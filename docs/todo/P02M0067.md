# P02M0067 - ISO9660: second-pass findings (the rare-legal shapes that misread)

Status: COMPLETE. The second full source pass (2026-07-04) found no high or medium issues left - what
remained were **rare but legal record shapes the reader served wrong instead of refusing**.

*Condensed 2026-08-08.*

- **The Extended Attribute Record length was ignored.** A nonzero value means the extent begins with
  that many XAR blocks and the data follows - so a file with one served the XAR block as its content
  prefix, and a directory with one parsed it as records. The entry's address advances past it now.
- **Interleaving was ignored**, so an interleaved file read contiguously served its gap blocks as
  content. Refused as unsupported, alongside multi-extent - the same class of silent misread.
- Joliet detection tested the escape sequences only at the start of the field, so a descriptor
  listing several with UCS-2 not first was missed and names fell back.

The pattern across this pass: **serving the wrong bytes is worse than refusing**, and every one of
these was a flag the format defines and the reader did not consult.
