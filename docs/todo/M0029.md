# M0029 - Prototype file picker (powerbox)

Status: COMPLETE.

**Authority flows from the act of picking, not from ambient access.** A component with no filesystem
capability of its own reaches exactly one user-picked file, and nothing else.

*Condensed 2026-08-08.*

The picker service holds the trusted StorageService client. On a pick it opens the chosen file and
hands back **that one file as a handle**, transferred out of band - so what the caller receives is a
capability to one file rather than a path it could vary.

The Wasm host gained a second grant mode: in picker mode it is given **only** a picker client - no
storage client and no path of its own - so the component's read import can be serviced in no other
way. That is what makes the demonstration real rather than a convention: the alternative route does
not exist to be taken.

This is the concept's hard rule made concrete: no ambient authority, and a user gesture as the thing
that creates a capability.
