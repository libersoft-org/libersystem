# P02M0187 - A media import service

Status: OPEN. It closes when every item below is done, and not before.

**A CAMERA IS NOT A BLOCK VOLUME, AND MOUNTING IT AS ONE IS THE MISTAKE THIS AVOIDS.** P02M0099's
PTP item says it directly: stream bounded object chunks through a media/import service rather than
mounting a camera as an arbitrary block volume. A device that answers "here are my objects and
their metadata" is not a filesystem, and presenting it as one means inventing a directory tree,
inventing modification times, and giving a client write access to a namespace the device does not
have.

**AND IT EXISTS BECAUSE THE OWNER SAID SO (2026-09-21)**, answering P02M0099's question about the
nine unowned destinations.

## The shape

- [ ] A typed `liber:import@1` interface: devices, their storages, a PAGINATED enumeration of
  objects with typed metadata, and a bounded chunked read of one object. Paginated because a camera
  with forty thousand photographs is an ordinary camera, and an enumeration that returns them all
  is an allocation nobody bounded.
- [ ] READ-ONLY FIRST AND MUTATION BEHIND ITS OWN CAPABILITY. Deleting an object or triggering a
  capture are destructive and irreversible on somebody's photographs; they are a separate
  capability from importing, and the ordinary client of an import gets the second and not the
  first.
- [ ] Object metadata typed rather than passed through: an identity, a format, a size, a capture
  time and a parent. Anything the device reports that this vocabulary does not name is carried
  unparsed and marked as such, rather than dropped or guessed at.
- [ ] Transfer that survives a device leaving mid-object, reported as a partial import rather than
  as a file.
- [ ] Host tests over the container length and transaction-id validation and the pagination, with
  the malformed and truncated cases.
- [ ] A guest gate over an emulated device, registered in the verification model in the same change.

## Definition of done

Done when a client holding the import capability can page through a device's objects and read one
in bounded chunks; when nothing in that path can delete or capture; when a device removed mid-
transfer produces a partial import that says so; when the validation and pagination are host-tested
against hostile input; and when the guest gate and its model entry land with the code.

## What it unblocks

P02M0099's **USB Picture Transfer Protocol (PTP)**.
