# P00M0005 - Object and capability core

Status: COMPLETE. Pure data-structure work - no arch or boot wiring. *Condensed 2026-08-08.*

Every kernel object embeds a header with a unique koid **plus a generation counter, which is what
makes revocation O(1)**.

`Rights` is a 12-bit bitset with subset checks: read, write, map, send, receive, duplicate, transfer,
revoke, wait, manage and the rest. A `Capability` is an object reference plus rights, a badge, and a
**snapshot of the generation** - so a stale handle is detectable rather than dangling.

The handle table hands out opaque handles encoding generation and index, with:

- lookup that enforces rights, and a typed lookup that seals the object type,
- **duplication that can only attenuate**, never widen,
- close that recycles the slot **and bumps its generation, so the old handle value dies**.

Six tests cover create/lookup/close, rights enforcement, attenuating duplication, O(1) revocation,
type sealing and refcount lifetime.
