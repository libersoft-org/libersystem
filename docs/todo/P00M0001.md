# P00M0001 - Skeleton (bring-up)

Status: COMPLETE. *Condensed 2026-08-08 - the task list is gone, the substance is below.*

`kmain` is the linker script's entry: serial first (COM1 16550), then a hand-rolled GDT with a TSS
carrying an IST double-fault stack, then an IDT filling all 32 exception vectors. Panics print to
serial and exit QEMU on the test path.

The test harness runs under QEMU and reports through the debug-exit port, which is what makes
`cargo test` a real thing on a bare-metal target from the very first milestone.

One decision that stuck: **the breakpoint handler prints and RETURNS** - it is recoverable - while
every other exception halts. GDB attaches over the QEMU stub for single-stepping.
