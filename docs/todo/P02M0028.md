# P02M0028 - ISO9660 filesystem backend (read-only)

Status: COMPLETE. The cheapest interop win: optical and install media, with no allocation and no write
path at all.

*Condensed 2026-08-08. The three later audit passes (P02M0066-P02M0068) are where it became hostile-media
safe.*

The backend parses the volume descriptors, walks the directory records and reads files, taking Rock
Ridge or Joliet long names where present and plain 8.3 otherwise. It mounts behind the same volume
interface as everything else - **no new app-facing API**, which is the layering claim being cashed in
for the second time.

Host-testable through the shared block-device trait against an image fixture, with a live read in the
guest as the end-to-end check.
