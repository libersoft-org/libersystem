# P02M0015 - AudioService over virtio-sound (headless playback + capture)

Status: COMPLETE (playback 2026-06-24, reworked to interrupt-driven MSI-X 2026-06-25; capture,
multi-period gapless refill and `play <file>` carried into P02M0016).

*Condensed 2026-08-08.*

A userspace `virtio_snd` driver over the existing transport, and an `AudioService` exposing audio as
a **capability** over generated bindings - so a program that was not granted `audio-stream` cannot
make a sound.

The playback path was polled first and reworked to interrupt-driven MSI-X, which is the same
correction the GPU driver needed: a poll interval is a latency floor and a wasted core, and the
device already has a way to say when it wants something.

`beep [hz] [ms]` plays a synthesized square wave, which is the smallest thing that proves the whole
chain end to end.
