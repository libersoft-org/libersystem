# M0059 - exFAT write support (large removable media)

Status: COMPLETE. *Condensed 2026-08-08.*

exFAT was read-only, and large SD cards and USB drives - the ones past FAT32's 4 GB file cap - need to
be writable.

exFAT is close enough to FAT that the write path shares most of the existing machinery: allocate and
free chains through the **allocation bitmap**, update the FAT, and create, write and delete entries.
Files past 4 GB are supported, which is the reason the format exists.

Host-testable with write round trips against an image fixture, plus a live write in the guest.

*(The later FAT audit passes found several exFAT-specific interop defects here - the up-cased name
hash, the NoFatChain flag and the ValidDataLength read rule among them.)*
