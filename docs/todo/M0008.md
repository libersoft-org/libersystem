# M0008 - Userspace (ring 3)

Status: COMPLETE. The first userspace program runs and makes a capability-gated syscall.

*Condensed 2026-08-08.*

The GDT gains the user segments in the slots `sysret` mandates, plus a per-core ring-0 stack. Entering
ring 3 and returning are **a setjmp/longjmp pair**: entry parks the kernel stack pointer in per-CPU
state, builds a return frame, and drops to ring 3 with the bootstrap handle in a register.

**One `LSTAR` entry serves both callers.** The ring-0 self-call and the ring-3 syscall are
distinguished by the sign bit of the saved return address, so there is one entry point rather than
two that can drift.

Paging propagates the user bit down every level, and user pointers are range-validated at the
boundary.

One latent bug from M0003 was diagnosed here: **the per-CPU MSR constant was FS_BASE, not GS_BASE** -
correct-looking, and wrong in a way nothing had yet exercised.
