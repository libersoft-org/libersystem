# M0122 - Image viewer (the first graphical application)

Status: DONE (2026-07-25).

`imgview <vol://...>` is a governed console-launched ELF holding exactly `volumes + display +
input-keys` - the first program to use the M0121 app-platform layer.

*Condensed 2026-08-08.*

It content-sniffs BMP and PNG, decodes into bounded B8G8R8X8 storage, fits to the acquired surface,
and switches an oversized image to a native crop rather than allocating whatever the file asks for.
The decoders are dependency-free `no_std` with host suites over golden and corrupt fixtures.

## What the interaction work settled

The viewer went through a second pass on its controls, and the decisions are the part worth keeping:

- **A bounded viewport model** with explicit 5% zoom steps from 100% to 800%, centre-preserving
  transitions, letterboxed fit rendering, and panning clamped so it cannot leave the image.
- **Fit-to-screen stays stable**: arrow keys do not implicitly zoom or pan out of it. A mode that
  silently stops being the mode you chose is worse than one that refuses.
- **Held keys repeat** - zoom and pan are continuous while held, rather than one step per press.
- **Esc exits from both the serial console and the graphical surface**, which are two different input
  paths and had to be made to agree.
- Main-keyboard and numeric-keypad plus and minus share one zoom state, so holding either produces
  the same smooth repeat.
