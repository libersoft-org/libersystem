# M0032 - virtio-net receive path + the link/IP layer (Ethernet, ARP, IPv4, ICMP)

Status: COMPLETE.

M0031 built the RX and interrupt machinery; this put a network on top of it. On an edge device
networking is the core, so this was phase 2's priority.

*Condensed 2026-08-08.*

`driver.virtio-net` is interrupt-driven and answers the wire. The stack does Ethernet II, ARP, IPv4
with header checksums, and ICMP, with the interface coming up on a static address.

Two decisions worth keeping:

- **The typed primitives are canonical.** `MacAddr` and `Ipv4Addr` are types, not byte arrays that
  every layer re-interprets. An address that can only be constructed correctly cannot be passed
  incorrectly.
- **Fragmentation is refused rather than half-implemented.** A partial reassembly is a memory hazard
  and a correctness hazard at once.

`ping` is the first CLI over it, which is the smallest thing that proves the whole path.
