# M0006 - Syscall ABI

Status: COMPLETE. *Condensed 2026-08-08.*

The `syscall` instruction path programs the EFER, STAR, LSTAR and FMASK registers, with **FMASK
clearing the interrupt flag so the handler runs un-preemptible**. The register convention puts the
number in `rax` and the arguments in the usual four.

At this stage the call is issued from ring 0 and returns without changing privilege; the ring-3
transition came with M0008, and a single entry point ended up serving both.

The dispatch table is portable and the error convention is Linux-style - success is the value, an
error is a small negative - which keeps a syscall's return one register wide.

The minimal set: debug write, clock, memory-object create/map/unmap, and handle duplicate/close, all
operating on the current thread's handle table.
