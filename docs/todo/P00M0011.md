# P00M0011 - IPC latency benchmark (phase 0 gate)

Status: COMPLETE. **The concept's gate before higher layers were built on IPC.**

*Condensed 2026-08-08.*

| | measured |
|---|---|
| raw channel round trip | ~0.76 us |
| full syscall round trip | ~5.1 us |

Both inside the single-digit-microsecond budget the concept set as the condition for building on IPC
at all.

**Zero copy was confirmed empirically, not argued**: a 1 MB buffer transferred with a three-byte
message, and the far-end marker read back through the moved capability.

The numbers are printed at boot and asserted by a test, so a regression is visible rather than
discovered later as "the system feels slow".
